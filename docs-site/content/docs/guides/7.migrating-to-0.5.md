# Migrating to 0.5

`0.5` upgrades `@circle-rd/auth-ai` to `0.5.0` and adds self-service teams.

## Required changes

1. Upgrade the SDK:
   ```bash
   pnpm add @circle-rd/auth-ai@^0.5.0
   ```
2. If you use the auth-ai sign-in client, set `teamManagement: true` to request
   `organizations:self:manage` and the auth-service audience. Existing
   `resourceSharing` and `gatewayUrl` options can be combined.
3. Refusals from the organizations API are `API_001` with `details.apiCode`
   carrying the `ORG_*` code.

## Teams

```ts
const organizations = createOrganizationsClient({
  config,
  token: request.authToken,
});

const teams = await organizations.listOrganizations({ team: true });
```

The helper forwards the verified token; OIDC does not mint or refresh tokens.
Applications that do not already hold an auth-service-scoped user token should
use the auth-ai `AiClient` with their `GrantManager` instead.
