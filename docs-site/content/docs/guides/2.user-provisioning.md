# User Provisioning

Both verification middlewares provision a local user when a `users` manager with
`findOrCreate` is registered.

```text
JWT verified → OidcUserContext { sub, email, name, … }
       │
       ▼
appHandle.users.findOrCreate(sub, { email, name })
       │
       ├─ User exists → return { id, role, isDisabled }
       └─ User missing → create → return { id, role, isDisabled }
       │
       ▼
isDisabled === true → 403 ERR_ACCOUNT_DISABLED
isDisabled === false → inject userId, userRole, … → proceed
```

`request.userId` / `socket.userId` is the local `users.id`, not the provider
`sub`. The `sub` remains available separately.

## Users manager

```ts
import { BaseManager } from "ioserver";

interface LocalUser {
  id: string;
  role: string;
  isDisabled: boolean;
}

class UsersManager extends BaseManager {
  async findOrCreate(
    sub: string,
    profile: { email: string | null; name: string | null },
  ): Promise<LocalUser> {
    let user = await db.users.findOne({ sub });
    if (!user) {
      user = await db.users.create({
        sub,
        email: profile.email,
        name: profile.name,
        role: "user",
        isDisabled: false,
      });
    }
    return { id: user.id, role: user.role, isDisabled: user.isDisabled };
  }
}

server.addManager({ name: "users", manager: UsersManager });
```

Without a users manager, `userId` falls back to `sub`. This is useful for
prototypes and services that do not keep a local user table.

## Disabling an account

```ts
await db.users.update({ sub }, { isDisabled: true });
```

The next request or connection is refused with `ERR_ACCOUNT_DISABLED`, even if
the JWT is still valid.

## Session tracking

`OidcSocketMiddleware` calls `appHandle.session.registerSocket(...)` and
`unregisterSocket(socket.id)` on disconnect when the manager exists. The socket
already carries `userId`, `sub` and `roles`:

```ts
class SessionManager extends BaseManager {
  private sockets = new Map<string, { userId: string; sub: string }>();

  registerSocket(socket: any, _namespace: string, _email: string | null, _name: string | null) {
    this.sockets.set(socket.id, { userId: socket.userId, sub: socket.sub });
  }

  unregisterSocket(socketId: string) {
    this.sockets.delete(socketId);
  }
}
```
