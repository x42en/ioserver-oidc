# Protected-resource metadata

```ts
import { registerProtectedResourceMetadata } from "ioserver-oidc";

registerProtectedResourceMetadata(server.getApp(), {
  config: buildConfig(),
  scopesSupported: ["gine:read", "gine:write"],
});
```

This serves `/.well-known/oauth-protected-resource...` with the resource,
authorization server, bearer method and optional scopes. `config.audience` must
be an absolute resource URL.

Set `OIDC_RESOURCE_METADATA_URL` and `OIDC_SCOPES_SUPPORTED` so the HTTP
middleware advertises the document in `WWW-Authenticate`:

```env
OIDC_RESOURCE_METADATA_URL=https://api.example.com/.well-known/oauth-protected-resource
OIDC_SCOPES_SUPPORTED=gine:read,gine:write
```

Without a metadata URL, the middleware keeps the simpler
`Bearer realm="api"` challenge.
