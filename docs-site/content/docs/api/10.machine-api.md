# Machine API

`OidcMachineManager` builds the confidential auth-service client and exposes
the auth-ai machine API through `appHandle.oidcMachine`.

```ts
server.addManager({ name: "oidcConfig", manager: OidcConfigManager });
server.addManager({ name: "oidcMachine", manager: OidcMachineManager });
```

```env
AUTH_SERVICE_CLIENT_SECRET=<confidential-client-secret>
```

The machine API is native auth-service only. The secret is never exposed in
`OidcConfig`, logged, or copied onto a request.

| Member | Description |
| --- | --- |
| `resources` | Resource sharing: `authorize`, `listAccessible`, `validate`, `invalidate`, `recordUsage` |
| `billing` | Subscription, usage and invoices for the application's users |
| `consumption` | Running totals: `report`, `listAggregates`, `getAggregate` |
| `api` | The full auth-ai `MachineApi` |

`resources:authorize` is a platform scope and belongs only to a trusted adapter
service. `resources:validate` is enough for a scheme validator;
`resources:usage:write` is reserved for metering components.
