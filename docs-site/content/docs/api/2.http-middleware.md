# OidcHttpMiddleware

`OidcHttpMiddleware` guards every route of a controller.

```ts
server.addController({
  name: "profile",
  controller: ProfileController,
  middlewares: [OidcHttpMiddleware],
});
```

## Flow

1. Extract `Authorization: Bearer <token>`.
2. Resolve `OidcConfig` from `appHandle.oidcConfig`, or from the environment.
3. Verify the signature, `iss`, `aud`, `azp` and expiry.
4. Refuse `client_credentials` tokens unless `allowMachineTokens` is enabled.
5. Provision the local user with `appHandle.users.findOrCreate(sub, { email, name })`
   when the manager exists.
6. Reject disabled accounts.
7. Inject the context onto the request.

## Injected context

| Property      | Type                     | Description                                      |
| ------------- | ------------------------ | ------------------------------------------------ |
| `sub`         | `string`                 | Stable provider user id                          |
| `userId`      | `string`                 | Local `users.id`, else `sub`                     |
| `userRole`    | `string`                 | Local role, else `roles[0]`, else `"user"`       |
| `roles`       | `string[]`               | Role names                                       |
| `permissions` | `string[]`               | Permission strings                               |
| `features`    | `Record<string,unknown>` | Plan features                                    |
| `plan`        | `string \| null`         | Plan name                                        |
| `sid`         | `string \| null`         | Provider session id                              |
| `clientId`    | `string \| null`         | Authorized party                                 |
| `scopes`      | `string[]`               | Granted scopes                                   |
| `isMachine`   | `boolean`                | True for an accepted machine token               |
| `org_id`      | `string`                 | Organization id, only when present               |
| `auth`        | `OidcUserContext`        | Complete verified context                        |
| `authToken`   | `string`                 | Raw bearer token; never log it                   |

## Errors

| Code                          | Status | Condition                                  |
| ----------------------------- | ------ | ------------------------------------------ |
| `ERR_AUTH_TOKEN_REQUIRED`     | 401    | Missing or malformed `Authorization`       |
| `ERR_AUTH_TOKEN_INVALID`      | 401    | Signature or claims verification failed    |
| `ERR_MACHINE_TOKEN_FORBIDDEN` | 403    | `client_credentials` token on a user route |
| `ERR_ACCOUNT_DISABLED`        | 403    | Local account is disabled                  |
| `ERR_USER_PROVISION_FAILED`   | 500    | `users.findOrCreate` threw                 |

Response shape:

```json
{
  "statusCode": 401,
  "error": "Unauthorized",
  "code": "ERR_AUTH_TOKEN_REQUIRED",
  "message": "Bearer token required."
}
```
