# OidcConfigManager

`OidcConfigManager` extends `BaseManager` and provides a validated, cached OIDC
configuration to sibling middlewares.

## Registration

```ts
import { OidcConfigManager } from "ioserver-oidc";

server.addManager({ name: "oidcConfig", manager: OidcConfigManager });
```

The name **must** be `"oidcConfig"`.

## Behaviour

The constructor selects the provider (`auth-service` by default, or `oidc`
when `OIDC_PROVIDER=oidc`), validates the required variables, and stores the
resolved `OidcConfig`. Missing configuration crashes at startup instead of
failing on the first request.

## Methods

### `start(): Promise<void>`

Called by IOServer during startup for logging. Validation already happened in
the constructor and throws on a missing native URL/slug, a missing generic
issuer/JWKS/audience/client id, an unsupported provider, an invalid boolean or
an out-of-range clock tolerance.

### `getConfig(): OidcConfig`

Returns the configuration validated by the constructor.
