# LiteLLM gateway client

`createGatewayClient()` and `createRequestGatewayClient()` return the
`GatewayClient` from `@circle-rd/auth-ai`, wired with a user token minted for the
gateway audience.

## `createGatewayClient(options)`

```ts
import { createGatewayClient } from "ioserver-oidc";

const gateway = createGatewayClient({
  gatewayUrl: "https://llm.example.com",
  token: request.authToken,
});

const models = await gateway.listModels();
const reply = await gateway.postJson("/v1/chat/completions", {
  model: "gpt-4o-mini",
  messages: [{ role: "user", content: "Hello" }],
});
```

| Option       | Required | Description                                      |
| ------------ | -------- | ------------------------------------------------ |
| `gatewayUrl` | Yes      | Public gateway URL, no trailing slash            |
| `token`      | Yes      | User token minted for the gateway audience       |
| `fetch`      | No       | Custom fetch implementation                      |
| `timeoutMs`  | No       | Request timeout, 10 s by default                 |

`GatewayClient` exposes `openAiBaseUrl`, `fetch`, `getAccessToken()`,
`listModels()`, `listAgents()`, `listMcpServers()`, `mcpUrl(serverName?)` and
`postJson(path, body)`.

## `createRequestGatewayClient(request, config)`

Builds the client from the `authToken` injected by the middleware and
`AUTH_SERVICE_GATEWAY_URL`:

```ts
const gateway = createRequestGatewayClient(request, config);
```

It throws when the request is not authenticated or the gateway URL is missing.

## Errors

Gateway failures use the auth-ai registry:

| Status | Code     | Meaning                                      |
| ------ | -------- | -------------------------------------------- |
| `402`  | `GW_001` | The wallet cannot pay for this call          |
| `429`  | `GW_002` | Gateway rate limit reached                    |
| `401`  | `GW_003` | Credentials or resource refused               |
| `403`  | `GW_003` | Resource or plan access refused               |
| `503`  | `GW_004` | Gateway unavailable                           |
| other  | `GW_005` | Unexpected answer                             |

`isInsufficientCredit(error)` is re-exported for convenience.
