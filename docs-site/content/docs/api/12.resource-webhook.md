# Resource webhooks

```ts
import { registerResourceWebhook } from "ioserver-oidc";

registerResourceWebhook(server.getApp(), {
  secret: process.env.AUTH_SERVICE_RESOURCE_WEBHOOK_SECRET!,
  onEvent: async event => {
    await grants.sync(event);
  },
});
```

Call it before `server.start()`. The helper installs an **encapsulated** raw JSON
parser, so other JSON routes keep their parsed bodies. It verifies
`X-Auth-Service-Signature` over the raw body, with a 300-second timestamp window
by default.

| Option | Default | Description |
| --- | --- | --- |
| `path` | `/auth/resource-webhook` | Route path |
| `toleranceSeconds` | `300` | Accepted timestamp skew |
| `maxBodyBytes` | 64 KiB | Raw body limit |
| `replayStore` | in-process | Deduplicate on `eventId`; share it across replicas |

The route is outside OIDC authentication. It answers `204` for accepted or
duplicate events, `400` for an invalid delivery, and `500` if `onEvent` throws.
Responses never carry detail.
