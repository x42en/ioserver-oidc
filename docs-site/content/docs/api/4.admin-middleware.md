# OidcSocketAdminMiddleware

Role guard for Socket.IO namespaces. It must be chained **after**
`OidcSocketMiddleware`, which injects `socket.roles` and `socket.userRole`.

```ts
server.addService({
  name: "admin",
  service: AdminService,
  middlewares: [OidcSocketMiddleware, OidcSocketAdminMiddleware],
});
```

## Accepted roles

By default, the connection is accepted when `roles` contains `"admin"`.
Configure the list with `OIDC_ADMIN_ROLES` (or `AUTH_SERVICE_ADMIN_ROLES`), or
with the `adminRoles` field of the resolved `OidcConfig`:

```env
OIDC_ADMIN_ROLES=admin,owner
```

The middleware accepts the connection when any configured role is present.

## Errors

| Code            | Condition                              |
| --------------- | -------------------------------------- |
| `ERR_FORBIDDEN` | None of the accepted roles is present  |
