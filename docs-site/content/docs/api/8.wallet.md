# Wallet client

`createWalletClient()` reads the user's credit wallet with a token minted for the
auth-service audience and carrying `wallet:self:read`.

```ts
import { createWalletClient } from "ioserver-oidc";

const wallet = createWalletClient({
  authServiceUrl: config.authServiceUrl,
  token: request.authToken,
});

const account = await wallet.getAccount();
if (!account.canSpend) {
  return reply.redirect(wallet.topupUrl());
}
```

| Option           | Required | Description                          |
| ---------------- | -------- | ------------------------------------ |
| `authServiceUrl` | Yes      | auth-service public base URL         |
| `token`          | Yes      | User token for the auth-service audience |
| `fetch`          | No       | Custom fetch implementation          |
| `timeoutMs`      | No       | Request timeout, 10 s by default     |

## Methods

| Method                         | Returns                  | Description                                      |
| ------------------------------ | ------------------------ | ------------------------------------------------ |
| `getAccount()`                 | `WalletAccount`          | Balance, `canSpend`, `isUnlimited`, currency     |
| `getStats({ days })`           | `WalletStats`            | Spend by day, application, kind and model        |
| `getSessionUsage(id, { days })`| `WalletSessionUsage`     | Spend of one chat session                        |
| `listTransactions(options)`    | `WalletTransactionPage`  | Newest first, keyset-paginated                   |
| `getTopupOptions()`            | `TopupOptions`           | Whether online top-up is enabled                 |
| `topupUrl()`                   | `string`                 | Credit tab of the auth-service profile           |

Amounts are `bigint` micro-euros (`MICRO_PER_EUR = 1_000_000n`). The helpers
`formatEuros` and `MICRO_PER_EUR` are re-exported.

## Errors

- `API_001` — auth-service answered a non-2xx status.
- `API_002` — the answer is not JSON or does not match the expected schema.
- `CFG_001` — invalid client configuration.

No token is included in an error message or `details`.
